# THE OFF GRID

A fresh React + Vite clothing-brand storefront starter.

## Brand
**THE OFF GRID**
Tagline: **MOVE DIFFERENT.**

The visual direction is premium streetwear: bold typography, editorial product cards, monochrome foundation, strong sale accents, mobile-first responsive layout.

## Included in this first build
- Home page
- Shop page
- Product detail page
- Search
- Category filters
- Sort
- Wishlist
- Cart drawer
- Quantity controls
- Free-shipping progress
- Checkout-ready cart summary
- Account page
- Responsive navigation
- Newsletter section
- Product badges
- LocalStorage for cart and wishlist
- Clean component structure for later backend/Razorpay/Admin integration

## GitHub / Render
This project is designed to be uploaded to GitHub without using a terminal.

For GitHub:
1. Create a new repository.
2. Upload the contents of this folder.
3. Commit changes.
4. For a static frontend, deploy the repository on Render as a **Static Site**.
5. Build command: `npm run build`
6. Publish directory: `dist`

You can also use GitHub's **Add file → Upload files** and upload the project files.

## Important
Product images currently use remote Unsplash image URLs so the site looks complete immediately. Replace them later with your own product photography.
